# Object Detection AI Website

This website uses TensorFlow.js and the COCO-SSD model to detect objects held in front of the camera in real-time.

## Features
- Real-time object detection using COCO-SSD model
- Camera access with bounding box overlay
- Live confidence scores
- Mobile-friendly interface

## Deployment
Deployed via GitHub Pages.

## Usage
1. Open the website
2. Click "Start Camera"
3. Hold an object in front of the camera
4. See real-time detection results

## Tech Stack
- HTML5 / CSS3
- JavaScript (ES6+)
- TensorFlow.js
- COCO-SSD Model
- Express.js (local development server)
